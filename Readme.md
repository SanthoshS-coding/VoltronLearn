# Voltron Learn

Voltron Learn is a small beginner-friendly course website about AI engineering basics. I am building it as a solo learning project with plain HTML, CSS, and JavaScript.

## About the project
I wanted to make a first introduction to AI engineering feel clear and approachable, rather than turning it into a wall of technical terms. The first batch uses short lessons, a simple example, and a small prompt experiment.

The first batch is planned as a one-hour overview. I might still need to check the lesson material and improve the activities so, the timing and content are for a future version(the v2).

## What the site includes

- Seven short lesson sections with estimated times.
- A lesson window with a mark-as-complete button.
- Progress saved in the browser.
- A personal notes area saved in the browser.
- Downloadable notes and practice files.
- A responsive layout for smaller screens.

Progress and notes are stored locally on the device. They are not shared with other learners, and there are no user accounts or server database in this version.

Keep the files in this structure so the page can find its stylesheet, JavaScript, and handouts.

## Run its
There is no package install or build step.

1. Download or clone the project.
2. Open `index.html` in a modern browser, or run the folder with VS Code Live Server.
3. Keep `style.css`, `app.js`, and the `files` folder beside `index.html`.
